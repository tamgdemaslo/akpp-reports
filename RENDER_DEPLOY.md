## Шаг 2: Настройка Render

### 2.1. Создайте аккаунт на Render

1. Перейдите на https://render.com
2. Зарегистрируйтесь через GitHub (рекомендуется)
3. Подключите ваш GitHub аккаунт

### 2.2. Создайте новый Web Service

1. В Dashboard нажмите **"New +"** → **"Web Service"**
2. Выберите ваш репозиторий `akpp-generator`
3. Настройте параметры:
   - **Name:** `akpp-generator`
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** `Free` (или выберите платный план)

4. Нажмите **"Create Web Service"**

### 2.3. Render автоматически:

- Установит зависимости
- Запустит сервер
- Присвоит URL вида: `https://akpp-generator.onrender.com`

### 2.4. Проверьте работу

- Откройте `https://ваш-сервис.onrender.com/status` - должен вернуть JSON со статусом
- Откройте `https://ваш-сервис.onrender.com/` - должна открыться главная страница

## Шаг 3: Настройка домена с reg.ru

### 3.1. В панели управления reg.ru

1. Войдите в личный кабинет reg.ru
2. Перейдите в раздел **"Домены"**
3. Выберите ваш домен
4. Перейдите в **"DNS-серверы и зоны"**

### 3.2. Настройте DNS записи

Добавьте следующие записи:

#### Для основного домена (например, `akpp-generator.ru`):

**A-запись:**
- **Тип:** A
- **Имя:** `@` (или оставьте пустым для корневого домена)
- **Значение:** IP адрес Render (см. ниже)
- **TTL:** 3600

**CNAME для www:**
- **Тип:** CNAME
- **Имя:** `www`
- **Значение:** `ваш-сервис.onrender.com`
- **TTL:** 3600

#### Как узнать IP адрес Render:

Render использует динамические IP, поэтому лучше использовать CNAME. Но если нужен A-запись:

```bash
# Выполните в терминале
nslookup ваш-сервис.onrender.com
```

Или используйте онлайн-сервисы типа `whatismyipaddress.com` для проверки IP Render.

**⚠️ Важно:** Render рекомендует использовать CNAME вместо A-записи для лучшей работы.

### 3.3. Альтернативный вариант (рекомендуется)

В reg.ru настройте:

**CNAME для корневого домена:**
- **Тип:** CNAME
- **Имя:** `@`
- **Значение:** `ваш-сервис.onrender.com`
- **TTL:** 3600

**CNAME для www:**
- **Тип:** CNAME
- **Имя:** `www`
- **Значение:** `ваш-сервис.onrender.com`
- **TTL:** 3600

## Шаг 4: Подключение домена в Render

### 4.1. В панели Render

1. Откройте ваш сервис `akpp-generator`
2. Перейдите в раздел **"Settings"**
3. Прокрутите до секции **"Custom Domains"**
4. Нажмите **"Add Custom Domain"**

### 4.2. Добавьте домен

1. Введите ваш домен: `akpp-generator.ru` (или ваш домен)
2. Нажмите **"Add"**
3. Render покажет инструкции по настройке DNS

### 4.3. Проверка DNS

Render автоматически проверит настройки DNS. Это может занять от нескольких минут до 24 часов.

**Проверить статус:**
- В Render Dashboard → ваш сервис → Custom Domains
- Статус должен быть **"Valid"** (зеленый)

---

## Шаг 5: Настройка SSL (HTTPS)

### 5.1. Автоматический SSL от Render

Render автоматически выдает SSL сертификаты через Let's Encrypt:

1. После успешной настройки DNS
2. Render автоматически запросит SSL сертификат
3. Через несколько минут HTTPS будет доступен

### 5.2. Проверка SSL

- Откройте `https://ваш-домен.ru`
- Должен быть зеленый замочек в браузере

## Устранение проблем

### Домен не работает

1. **Проверьте DNS:**
   ```bash
   # Проверьте DNS записи
   nslookup ваш-домен.ru
   dig ваш-домен.ru
   ```

2. **Подождите распространения DNS:**
   - Обычно 5-30 минут
   - Может занять до 24 часов

3. **Проверьте настройки в Render:**
   - Custom Domains → статус должен быть "Valid"

### Сервер не запускается

1. **Проверьте логи в Render:**
   - Dashboard → ваш сервис → Logs

2. **Проверьте package.json:**
   - Убедитесь, что `start` команда правильная
   - Проверьте зависимости

3. **Проверьте переменные окружения:**
   - Settings → Environment Variables

### Прокси не работает

1. **Проверьте URL в HTML:**
   - Должны быть относительные пути: `/proxy/rossko`
   - Не `http://localhost:5001/proxy/rossko`

2. **Проверьте CORS:**
   - В `server.js` должен быть `app.use(cors())`
