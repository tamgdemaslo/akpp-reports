## 🚀 Шаг 2: Настройка Render

### 2.1. Создайте аккаунт
- Перейдите на https://render.com
- Зарегистрируйтесь через GitHub

### 2.2. Создайте Web Service

1. **New +** → **Web Service**
2. Выберите репозиторий: `tamgdemaslo/akpp-reports`
3. Настройки:
   - **Name:** `akpp-generator`
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Plan:** `Free`

4. Нажмите **Create Web Service**

### 2.3. Render автоматически:
- Установит зависимости
- Запустит сервер
- Присвоит URL: `https://akpp-generator-xxxx.onrender.com`

---

## 🌐 Шаг 3: Настройка домена reg.ru

### 3.1. В панели reg.ru

1. Войдите в личный кабинет
2. Домены → выберите ваш домен
3. DNS-серверы и зоны

### 3.2. Добавьте CNAME записи:

**Для корневого домена (@):**
- Тип: **CNAME**
- Имя: `@`
- Значение: `ваш-сервис.onrender.com` (например: `akpp-generator-xxxx.onrender.com`)
- TTL: 3600

**Для www:**
- Тип: **CNAME**
- Имя: `www`
- Значение: `ваш-сервис.onrender.com`
- TTL: 3600

### 3.3. В Render

1. Откройте ваш сервис
2. Settings → Custom Domains
3. Add Custom Domain
4. Введите: `ваш-домен.ru`
5. Нажмите Add

### 3.4. Ожидание

- DNS распространяется 5-30 минут (до 24 часов)
- Render автоматически выдаст SSL сертификат
- Статус в Render должен стать "Valid" (зеленый)

## 🆘 Проблемы?

1. **Домен не работает:** подождите распространения DNS (до 24 часов)
2. **Сервер не запускается:** проверьте логи в Render Dashboard
3. **Прокси не работает:** убедитесь, что в HTML используются относительные пути `/proxy/rossko`
