# Узловые схемы АКПП

Эта папка содержит изображения узловых схем для различных моделей АКПП.

## Структура файлов

Изображения должны быть названы по следующему формату:
`{gearbox_key}_description.jpg` или `.png`

Например:
- `dq250_02e_engine_bay.jpg` - схема под капотом для DQ250
- `dq250_02e_underbody.jpg` - схема снизу для DQ250

## Добавление схем для новой АКПП

1. Добавьте изображения в эту папку
2. Обновите файл `gearbox_files/{model}.js`, добавив поле `schematics`:

```javascript
"schematics": [
  {
    "image": "images/gearbox_schematics/{filename}.jpg",
    "title": "Название схемы",
    "description": "Краткое описание",
    "annotation": "**Важно:** Дополнительная информация с форматированием"
  }
]
```

## Формат аннотаций

В поле `annotation` можно использовать:
- `**текст**` для жирного текста
- Обычный текст для описаний

Примеры:
- `"**Проверка уровня:** Внутри переливная трубка. **Температура:** 35–45 °C"`
- `"**Доступ:** Снять воздушный фильтр и аккумуляторную площадку."`
