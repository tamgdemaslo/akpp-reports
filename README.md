# Генератор отчетов АКПП - Унифицированная система стилей

![Статус проекта](https://img.shields.io/badge/статус-готов-brightgreen)
![Версия](https://img.shields.io/badge/версия-2.0-blue)
![Лицензия](https://img.shields.io/badge/лицензия-MIT-yellow)

Профессиональный инструмент для генерации отчетов по замене масла в автоматических коробках передач (АКПП). Система была модернизирована для использования единой системы стилей (design system) для всех HTML файлов. Основные стили вынесены в отдельный файл `common-styles.css`, что обеспечивает консистентность дизайна и упрощает поддержку.

## 🚀 Особенности

- **🎨 Единая система стилей** - все страницы используют общие стили
- **📱 Адаптивный дизайн** - поддержка всех устройств
- **⚡ Высокая производительность** - кэширование стилей браузером
- **🔧 Легкая поддержка** - изменения в одном файле применяются везде
- **🎯 Консистентность** - единообразный дизайн на всех страницах
- **📊 База данных 16 моделей КПП** от 4 производителей
- **🤖 Автоматическое заполнение** технических параметров
- **📄 Экспорт в PDF, JPG** и мобильную версию
- **📋 Детальные инструкции** по замене масла
- **💰 Калькулятор стоимости** с различными вариантами

### Ключевые файлы:

- **`common-styles.css`** - 🎨 Основной файл стилей с компонентами и переменными

- **`report_data.js`** - 📊 База данных с техническими параметрами и ценами
- **`yaml_to_js_converter.py`** - 🔄 Утилита для конвертации YAML в JavaScript

## 🛠️ Функциональность

### Основные возможности:

1. **Выбор КПП:**
   - Dropdown с производителями (ZF, Toyota, Aisin Warner, Jatco)
   - Динамическое обновление моделей при выборе производителя
   - Автозаполнение технических параметров

2. **Генерация отчета:**
   - Расчет стоимости стандартных и премиум материалов
   - Частичная и аппаратная замена масла
   - Дополнительные расходники
   - Скидки и специальные предложения

3. **Экспорт:**
   - PDF документ
   - JPG изображение
   - Мобильная версия JPG
   - Краткое резюме для соцсетей

4. **Инструкции:**
   - Переход на отдельную страницу
   - Полная техническая информация
   - Пошаговые инструкции
   - Современное оформление

## 🎯 Поддерживаемые модели КПП

### ZF (3 модели):
- ZF 6HP19 / 6HP21
- ZF 6HP28 / 6HP26 / 6HP32
- 8HP45/50/51/75/76/90

### Toyota (4 модели):
- U660E / U760E
- U880E / U881E
- CVT K110 / K111 / K112 / K114
- CVT K310 / K311 / K312

### Aisin Warner (3 модели):
- TR-80SD (0C8)
- TR-60SN (09D)
- TF-60SN (09G)

### Jatco (4 модели):
- JF015E (RE0F11A)
- JF016E (RE0F10D)
- JF017E (RE0F10E-H)
- JF018E (RE0F03H / RE0F02H)

## 📋 Техническая информация

Для каждой модели КПП в базе данных содержится:

- **Объем слива** (литры)
- **Тип и спецификация жидкости**
- **Рабочая температура**
- **Моменты затяжки** (поддон, сливная пробка, заливная пробка)
- **Артикулы фильтров** и цены
- **Расходные материалы** и их стоимость
- **Детальная процедура замены**

## 🚀 Использование

### Запуск проекта:

1. **Скачайте все файлы** в одну папку
2. **Откройте `akpp_generator_modern.html`** в веб-браузере
3. **Выберите производителя и модель** из списков
4. **Заполните дополнительные параметры** (при необходимости)
5. **Нажмите "Создать отчет"** для генерации

### Получение инструкций:

1. **Выберите модель КПП** из списка
2. **Нажмите "Получить инструкцию"**
3. **Откроется новая страница** с подробной информацией
4. **Просмотрите технические параметры** и пошаговую инструкцию

### Экспорт отчетов:

- **PDF** - для печати и архивирования
- **JPG** - для отправки по email
- **Мобильный JPG** - оптимизированный для телефонов
- **Краткое резюме** - для соцсетей и мессенджеров

## 🔄 Обновление данных

Для обновления базы данных из YAML файлов используйте скрипт `yaml_to_js_converter.py`:

### Конвертация YAML в JS:

1. **Запустите скрипт из каталога проекта:**
   ```bash
   python3 yaml_to_js_converter.py
   ```

2. **Или используйте полный путь к скрипту:**
   ```bash
   python3 /Users/ilaeliseenko/Desktop/akpp-generator/yaml_to_js_converter.py
   ```

**Примечание:** Скрипт автоматически:
- Читает YAML файлы из каталога `/Users/ilaeliseenko/Desktop/акпп бот/`
- Конвертирует их в JavaScript формат
- Сохраняет результат в файлы `report_data.js` и `instructions_data.js` в каталоге проекта

### Требования для конвертации:
- **Python 3.x** с установленным модулем `pyyaml`
- **YAML файлы** в исходном каталоге
- **Права на запись** в каталог проекта
