# Описание для Gamma: Генератор отчетов АКПП

## Обзор проекта

Создай современный веб-сайт для генератора отчетов по замене масла в автоматических коробках передач (АКПП). Это профессиональный инструмент для автосервисов, который помогает механикам быстро создавать технические отчеты с расчетом стоимости.

## Главная страница

### Заголовок
- Крупный заголовок: "Генератор отчетов АКПП"
- Подзаголовок: "Профессиональный инструмент для автосервисов"
- Градиентный фон: фиолетово-синий градиент (#667eea → #764ba2)
- Белый текст, современная типографика

### Двухколоночный layout

**Левая панель (360px) - Форма:**
- Выбор производителя КПП (ZF, Toyota, Aisin Warner, Jatco)
- Выбор модели КПП
- Поля для технических параметров
- Кнопка "Создать отчет" (крупная, привлекающая внимание)
- Кнопка "Получить инструкцию"
- Белый фон, легкая тень, скругленные углы

**Правая панель - Предпросмотр отчета:**
- Технические характеристики в таблицах
- Расчет стоимости материалов
- Объем масла, температура, моменты затяжки
- Кнопки экспорта: PDF, JPG, Мобильная версия
- Структурированная информация с визуальным выделением важных параметров

## Дизайн-система

### Цвета
- Основной градиент: #667eea → #764ba2 (фиолетово-синий)
- Альтернативный: #0066cc → #3385d6 (синий)
- Успех: #28a745 (зеленый)
- Ошибка: #dc3545 (красный)
- Предупреждение: #ffc107 (желтый)
- Фон: #f5f5f5 (светло-серый)
- Поверхности: #ffffff (белый)

### Типографика
- Шрифт: Inter, система шрифтов (San Francisco, Segoe UI, Roboto)
- Заголовки: 32-42px, жирность 700
- Основной текст: 14-16px, жирность 400-600
- Мелкий текст: 12-13px

### Компоненты

**Карточки:**
- Белый фон
- Скругление 12px
- Тени для глубины
- Hover эффект: подъем карточки, изменение тени

**Кнопки:**
- Основная: градиентный фон, белый текст, скругление 8px
- Вторичная: прозрачный фон, цветная граница
- Hover: легкое увеличение, изменение тени

**Формы:**
- Поля ввода: белый фон, граница 2px, скругление 8px
- Focus: цветная рамка и тень
- Валидация: красная рамка при ошибке

**Таблицы:**
- Заголовок: цветной фон, белый текст
- Строки: чередование цветов
- Hover эффект на строках

## Функциональность

### Основные возможности
1. Выбор из 16 моделей КПП от 4 производителей
2. Автоматическое заполнение технических параметров
3. Расчет стоимости стандартных и премиум материалов
4. Генерация детальных отчетов
5. Экспорт в PDF, JPG, мобильную версию
6. Переход к пошаговым инструкциям

### Технические данные
- Объем слива масла (литры)
- Тип и спецификация жидкости
- Рабочая температура
- Моменты затяжки (поддон, пробки)
- Артикулы фильтров и цены
- Расходные материалы и стоимость

## Страница инструкций

### Структура
- Заголовок с названием модели КПП и производителем
- Навигация: хлебные крошки, кнопка "Назад"
- Секция технических характеристик (таблицы, карточки)
- Пошаговая инструкция (нумерованный список)
- Дополнительная информация (предупреждения, советы)
- Визуализация: схемы, иконки для каждого шага

## Адаптивность

### Desktop (≥ 1024px)
- Двухколоночный layout
- Полная функциональность
- Все элементы видны одновременно

### Планшет (768px - 1023px)
- Адаптивная сетка
- Панель формы становится выдвижной
- Предпросмотр занимает всю ширину

### Мобильный (< 768px)
- Одноколоночный layout
- Панель формы сворачиваемая
- Упрощенные таблицы
- Оптимизированные размеры кнопок

## UX принципы

1. Быстрый доступ - все функции за 1-2 клика
2. Визуальная иерархия - четкое разделение важной информации
3. Обратная связь - индикаторы загрузки, успеха, ошибок
4. Прогрессивное раскрытие - сложная информация по запросу
