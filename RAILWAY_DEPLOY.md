# 🚂 Деплой на Railway

## Быстрый старт

1. **Создайте аккаунт на Railway**
   - Перейдите на https://railway.app
   - Войдите через GitHub

2. **Создайте новый проект**
   - Нажмите "New Project"
   - Выберите "Deploy from GitHub repo"
   - Выберите ваш репозиторий `akpp-generator`

3. **Railway автоматически:**
   - Определит Node.js проект
   - Установит зависимости из `package.json`
   - Запустит `npm start` (который запускает `server.js`)
   - Назначит порт автоматически через переменную `PORT`

## Переменные окружения

Railway автоматически устанавливает переменную `PORT`. Если нужны дополнительные переменные:

1. В проекте Railway перейдите в **Variables**
2. Добавьте необходимые переменные:
   - `PORT` - устанавливается автоматически
   - `NODE_ENV=production` - для production режима

## Проверка деплоя

После деплоя Railway предоставит URL вида:
```
https://your-project-name.up.railway.app
```

## Обновление проекта

1. Сделайте изменения в коде
2. Закоммитьте и запушьте в GitHub:
   ```bash
   git add .
   git commit -m "Update project"
   git push origin main
   ```
3. Railway автоматически пересоберет и задеплоит проект

## Структура проекта для Railway

- `package.json` - определяет зависимости и start script
- `server.js` - основной сервер (Express)
- `railway.json` - конфигурация Railway (опционально)
- `.gitignore` - исключает ненужные файлы

## Проблемы и решения

### Порт не определен
Railway автоматически устанавливает `PORT`. Убедитесь что `server.js` использует:
```javascript
const PORT = process.env.PORT || 3000;
```

### Зависимости не установлены
Проверьте что `package.json` содержит все необходимые зависимости:
- express
- cors
- node-fetch

### Статические файлы не отдаются
Убедитесь что `server.js` правильно настроен для отдачи статических файлов:
```javascript
app.use(express.static(__dirname));
```

## Мониторинг

Railway предоставляет:
- Логи в реальном времени
- Метрики использования

## Домены

Railway предоставляет бесплатный домен. Для кастомного домена:
1. Перейдите в **Settings** → **Domains**
2. Добавьте ваш домен
3. Настройте DNS записи согласно инструкциям
