# 🚀 МАКСИМАЛЬНО ПРОСТАЯ СХЕМА РАБОТЫ

## Как запустить сайт?

```bash
./start.sh
```

Затем открой http://localhost:8080 в браузере

## Как добавить новую АКПП?

1. **Создай файл** в папке `gearbox_files/` с именем типа `НОВАЯ_АКПП.js`

2. **Скопируй структуру** из любого существующего файла, например из `ZF6HP28.js`:

```javascript
// НОВАЯ_АКПП данные
(function() {
    if (typeof window.allGearboxData === 'undefined') {
        window.allGearboxData = {};
    }
    
    window.allGearboxData['НОВАЯ_АКПП'] = {
        "manufacturer": "Производитель",
        "gearbox": "Название АКПП",
        "summary": "Краткое описание",
        "fluid": "Тип масла",
        "drain_volume": 5.0,
        // ... остальные поля
        "oem_json": {
            "oem_fluid_1": "Артикул масла",
            "oem_fluid_1_price": 1500,
            // ... OEM коды
        }
    };
    
    console.log('✅ Loaded НОВАЯ_АКПП gearbox data');
})();
```

3. **Обнови страницу** в браузере - файл сразу подключится!

## Файлы

- `start.sh` - запуск всего сайта одной командой
- `serve.js` - HTTP сервер с автообновлением индекса
- `auto_update_index.js` - обновляет список всех файлов АКПП
- `gearbox_files/` - папка со всеми АКПП (51 штука)
- `gearbox_files/gearbox_index.js` - автоматически обновляемый список файлов
