Создай современный веб-сайт для генератора отчетов по замене масла в автоматических коробках передач (АКПП).

ПРОЕКТ: Профессиональный инструмент для автосервисов и механиков, который автоматизирует создание технических отчетов с расчетом стоимости.

ГЛАВНАЯ СТРАНИЦА:

Заголовок:
- Крупный заголовок "Генератор отчетов АКПП"
- Подзаголовок "Профессиональный инструмент для автосервисов"
- Градиентный фон: фиолетово-синий (#667eea → #764ba2)
- Белый текст, современная типографика

Двухколоночный layout:

Левая панель (360px) - Форма:
- Выбор производителя КПП (ZF, Toyota, Aisin Warner, Jatco)
- Выбор модели КПП
- Поля для технических параметров
- Крупная кнопка "Создать отчет" с градиентным фоном
- Кнопка "Получить инструкцию"
- Белый фон, скругленные углы, легкая тень

Правая панель - Предпросмотр отчета:
- Таблицы с техническими характеристиками
- Расчет стоимости материалов
- Объем масла, температура, моменты затяжки
- Кнопки экспорта: PDF, JPG, Мобильная версия
- Визуальное выделение важных параметров

ДИЗАЙН:

Цвета:
- Основной градиент: #667eea → #764ba2
- Успех: #28a745 (зеленый)
- Ошибка: #dc3545 (красный)
- Фон: #f5f5f5
- Поверхности: #ffffff

Типографика:
- Шрифт: Inter, система шрифтов
- Заголовки: 32-42px, жирность 700
- Основной текст: 14-16px

Компоненты:
- Карточки: белый фон, скругление 12px, тени, hover эффект
- Кнопки: градиентный фон, скругление 8px, hover анимация
- Формы: белый фон, граница 2px, скругление 8px, focus состояние
- Таблицы: цветной заголовок, чередующиеся строки, hover эффект

ФУНКЦИОНАЛЬНОСТЬ:
- Выбор из 16 моделей КПП от 4 производителей
- Автоматическое заполнение технических параметров
- Расчет стоимости материалов
- Генерация детальных отчетов
- Экспорт в PDF, JPG
- Пошаговые инструкции

СТИЛЬ:
- Профессиональный и современный
- Минималистичный дизайн
- Техническая направленность
- Чистые линии, много белого пространства
- Плавные анимации и переходы
- Многослойные тени для глубины

АДАПТИВНОСТЬ:

- Мобильный: одноколоночный layout
